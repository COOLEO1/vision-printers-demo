# Pyramids Development & Investments Ltd — Website Concept Preview

A responsive, bilingual (English / Chichewa) website concept prepared by Golden-Rhys Company for Pyramids Development & Investments Ltd, Malawi.

## Render deployment
- Static Site
- Branch: `master`
- Build command: leave blank
- Publish directory: `.`

## Website features
- Pyramids company branding and responsive layout
- English / Chichewa language switch
- Product and solutions showcase: decorative paints, wood panels, cornices and interior finishing
- Inspiration gallery
- Blantyre and Lilongwe branch sections with Google Maps search directions
- Click-to-call phone numbers and click-to-email contact link
- Enquiry form that prepares text for copying (no backend submission)

## Accuracy and image notes
This is a website concept preview, not an official or approved Pyramids website. Product categories and descriptions are illustrative and should be confirmed with the business. Unsplash photographs are for visual inspiration only and do not depict verified Pyramids products, projects, staff, customers or premises. See `image-credits.html`.

The enquiry form does not submit data, send email, open WhatsApp, or store personal information. It only attempts to copy the visitor's enquiry text to their clipboard. No backend, database, payment system, inventory, live booking, or admin dashboard is included.

## Repository reuse
This repository is maintained as a reusable Golden-Rhys Company demo website. Before adapting it for another prospect, replace all business-specific copy, identity, contact details, imagery and location content, and verify every claim and contact route.
